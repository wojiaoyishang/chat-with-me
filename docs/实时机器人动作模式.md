# 机器人 3D 动作模式

## 使用

更新前后端并重启 API 和 Celery Worker。点击聊天页右上角的立方体 **3D 动作模式** 按钮即可打开独立浮窗，不需要麦克风或语音通话。动作与表情测试按钮默认隐藏；在设置 → 界面 → 聊天页面中开启「机器人调试」后可手动预览，该本地偏好即时生效并保存。无论开关是否启用，都可以打字让 AI 挥手、点头、摇头、点赞、跳舞或切换表情。通话窗口的 3D 按钮也操作同一浮窗。需要当前模型支持工具调用且相关工具权限未被禁用。新对话未创建时可以查看机器人，调试开启后允许手动预览，发送第一条消息创建对话后会绑定新场景；等场景加载完成后发送控制请求。

3D 模块按需加载，浮窗不阻挡聊天框打字。关闭浮窗、页面卸载或刷新会销毁场景，切换对话和聊天连接重建会建立新的场景，初始为待机与自然表情。结束或缩小通话不会关闭独立场景。移动端浮窗限制高度且内部可滚动。WebGL 不可用或模型加载失败会显示错误，可关闭并重开。

## 拖动与沉浸式模式

拖动窗口标题栏可以移动位置，桌面端右下角支持调整大小。点击标题栏「放大」进入沉浸式模式，场景铺满当前 ChatPage；点击「还原」或按 Escape 返回浮窗。浮窗位置与尺寸保存在本机；不会保存动作或场景会话。

沉浸式模式中，将鼠标移到 ChatPage 底部约 96 像素区域即可浮现原有 ChatBox；进入输入框或输入框获得焦点后保持显示，移开且失去焦点后延迟约 700ms 收起。手机或键盘用户可点击/聚焦底部「输入消息」按钮唤出。输入框始终挂载，附件、草稿、工具和发送逻辑不另建副本，且沉浸式模式禁用 ChatBox 自身的折叠显示，避免两套隐藏规则互相影响。

复用 components/window/FloatingDockWindow 的拖动、调整大小和布局存储。新增可选 portalTarget、expanded、compactMobile、defaultLayout、zIndex 属性，未传入时保留原任务浮窗行为。窗口始终挂载在同一 ChatPage portal，放大/还原仅改变布局；AvatarScene 的场景生命周期依赖仍仅为请求适配器和 conversationId，ResizeObserver 适配渲染尺寸。ChatPage 内采用场景 50 / 输入框 60 / 唤出按钮 70 的局部层级，使现有全屏编辑器（100）及弹窗正常覆盖场景，不修改其他任务浮窗的默认层级。新增 useImmersiveComposer 只负责输入框显示状态与事件清理。

验证包含布局边界、移动端窄窗口、放大/还原、原有停靠、底部悬浮、焦点保持、触屏唤出和监听器清理，以及原场景协议与流式导航检查。浏览器临时组件页使用真实 FloatingDockWindow、useImmersiveComposer 和 Three.js 模型，确认拖动、区域铺满、草稿保留与模型只挂载一次；未进行带真实 AI 的完整聊天页面和真机移动端联调。

## 模块与契约

- 前端 `src/features/avatar-scene/`：AvatarScenePanel 提供独立浮窗与控制连接请求，AvatarScene 管会话与 UI，robotScene 管 Three.js、骨架动画与资源释放，commandGate 拒绝旧场景、错误页面、重复/过期命令。
- 后端 `application/avatar_scene/`：catalog.json 是动作/表情目录的唯一权威；service 管 Redis 临时租约、序号、命令确认。Worker 的 chat/avatar_scene.py 仅适配现有工具系统。
- 复用聊天控制 WebSocket 的 Protocol v1 二进制请求：avatar.scene.catalog/start/renew/stop/ack；复用现有 Redis EventBus 和控制 WebSocket 广播 avatar.pose.apply。没有增加第二套事件总线或历史回放入口。
- 模型完整加载并验证 clip/morph 后提交目录版本及支持列表。服务端签发 sceneSessionId，绑定 userId、conversationId、controlConnectionId；realtimeSessionId 保留为兼容字段，独立场景为 null；30 秒租约、10 秒续约。
- avatar_set_pose(pose_id, expression_id) 每次完整覆盖模板；单次动作结束回待机，跳舞持续到替换。为保持表情，过滤上游动画的 morph 权重轨道。当前不提供任意骨骼角度、物理交互或口型同步。
- 命令带 UUID、递增 sequence、版本、4 秒有效期；只当前挂载场景消费。Worker 等待前端 ACK 至多 3 秒，成功表示开始播放；不会把已发送等同于已执行。
- 场景能力在下一次文字或语音生成的工具快照中加入；打开场景不会修改已经运行的生成快照。客户端 options 中的 _voiceScene 和 _avatarScene 都被清除；服务端按已认证用户、当前对话和控制连接从 Redis 查询活动场景，再注入 _avatarScene，会话设置持久化排除内部绑定。控制连接断开主动清理租约，未完成的请求不进入离线队列。旧 Worker 工具调用再次验证租约，不能操作刷新后的新场景。
- 动作可在普通工具审计中保留文字记录，Redis 命令/ACK 仅短暂存在；关闭、过期或断线后不补播。PubSub 不提供离线重放，ACK 超时应视为失败。
