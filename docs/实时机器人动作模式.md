# 实时机器人动作模式（初版）

## 使用

更新前后端并重启 API 和 Celery Worker。开始实时语音通话，在右上角点击 **3D**。机器人加载完成后，可以点击动作/表情按钮预览，也可以在下一次语音消息中让 AI 挥手、点头、摇头、点赞、跳舞，或切换自然、生气、惊讶、难过表情。需要当前模型支持工具调用，工具权限未被禁用。

3D 模块按需加载，关闭按钮、缩小通话窗口、结束通话、页面刷新会销毁场景。重新打开从待机与自然表情开始。移动端场景区域可滚动，底部通话按钮独立保留。WebGL 不可用或模型加载失败会显示错误，可关闭并重开。

## 模块与契约

- 前端 `src/features/avatar-scene/`：AvatarScene 管会话与 UI，robotScene 管 Three.js、骨架动画与资源释放，commandGate 拒绝旧场景、错误页面、重复/过期命令。
- 后端 `application/avatar_scene/`：catalog.json 是动作/表情目录的唯一权威；service 管 Redis 临时租约、序号、命令确认。Worker 的 chat/avatar_scene.py 仅适配现有工具系统。
- 复用 RealtimeVoiceTransport 的 Protocol v1 二进制请求：voice.scene.catalog/start/renew/stop/ack；复用现有 Redis EventBus 和控制 WebSocket 广播 avatar.pose.apply。没有增加第二套事件总线或历史回放入口。
- 模型完整加载并验证 clip/morph 后提交目录版本及支持列表。服务端签发 sceneSessionId，绑定 userId、conversationId、controlConnectionId、realtimeSessionId；30 秒租约、10 秒续约。
- avatar_set_pose(pose_id, expression_id) 每次完整覆盖模板；单次动作结束回待机，跳舞持续到替换。为保持表情，过滤上游动画的 morph 权重轨道。当前不提供任意骨骼角度、物理交互或口型同步。
- 命令带 UUID、递增 sequence、版本、4 秒有效期；只当前挂载场景消费。Worker 等待前端 ACK 至多 3 秒，成功表示开始播放；不会把已发送等同于已执行。
- 场景能力在下一次语音生成的工具快照中加入；打开场景不会修改已经运行的生成快照。客户端 options 中的 _voiceScene 被清除，仅使用服务端通话绑定注入；会话设置持久化排除该字段。旧 Worker 工具调用再次验证租约，不能操作刷新后的新场景。
- 动作可在普通工具审计中保留文字记录，Redis 命令/ACK 仅短暂存在；关闭、过期或断线后不补播。PubSub 不提供离线重放，ACK 超时应视为失败。
