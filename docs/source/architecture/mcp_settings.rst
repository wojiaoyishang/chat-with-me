MCP 服务设置与工具目录刷新
================================================================================

管理员入口
--------------------------------------------------------------------------------

后端设置标签声明 ``component="mcp"``，前端懒加载 ``MCPSettings``。标签和所有管理接口
均由后端鉴权。表单分别支持 HTTP、SSE 和 Worker 本地命令；配置的命令不在浏览器执行。
新建服务、编辑服务和工具策略各自保存，设置页不再对该标签额外提交通用保存请求。

请求头和环境变量使用密码输入，不回显已有值。留空保留，删除行移除对应键；表单只提交
明确支持的配置字段，不把工具 Schema、检测结果或脱敏占位字段重新提交为配置。
本地命令的参数为 JSON 字符串数组，切换连接方式时清除不适用的字段。

工具发现与权限
--------------------------------------------------------------------------------

“测试连接”和“刷新工具”返回普通后台工作流任务。界面展示当前状态并允许打开任务详情；
轮询只获取进度，不重复提交检测。离开页面停止轮询，后台任务仍由服务端追踪。
发现的工具先显示新增、变更和移除清单，管理员确认后才发布。连接变更后显示重新发布提示。

工具策略支持服务默认值、每个工具覆盖，以及执行模式、反馈行为等高级 JSON 设置。
“用户管理”决定工具分配，“默认工具”及会话决定允许、询问、拒绝。MCP 权限与内建工具
共用既有组件；直接暴露与是否需要审批是独立设置。

实时刷新
--------------------------------------------------------------------------------

``tool.catalog.changed`` 是目录失效通知，不携带凭据或其他用户的工具清单。聊天输入区重新
读取授权目录，保留当前输入、角色和内建工具状态；返回浏览器页面时也重新核对目录。
用户管理只刷新工具目录，不丢弃正在编辑的用户信息和工具分配。
默认工具页面存在未保存更改时给出刷新提示，不直接覆盖表单。

工具名称与参数
--------------------------------------------------------------------------------

工具集标识和原始工具名称组成稳定路径，前端不解析 ``服务名_工具名``。
原始名称可含点号、连字符等字符；AI 的 Dispatcher、直接工具与受限 Python 均由后端
ToolRef 解析。设置页以原始 Schema 展示参数，不在前端另维护工具定义。
