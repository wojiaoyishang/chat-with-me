会话自消息入口与动态侧栏
================================================================================

功能边界
--------------------------------------------------------------------------------

会话自消息由主回复 Worker 完成持久化后直接提交独立后台任务，不使用 Schedule。
客户端只提供右上角入口、通用远程设置面板及已有的通用字段组件；规则、日志、动作和
编辑器均来自当前后端的 ``cwm.settings.v1`` 描述，不注册专用业务设置页面。

入口使用 ``GET /conversation-self-messages/conversations/{conversationId}/settings``，
由后端组织“配置”和“运行记录”标签页。两者复用表单草稿、资源列表、动态编辑对话框、
保存反馈与后端校验。模板使用共享代码编辑器，模型参数来自能力声明，上下文范围由
后端枚举与字段描述提供。

显示与加载
--------------------------------------------------------------------------------

面板加载和失败状态保留布局，结果自然淡入；关闭时保留内容直到退出动画结束。
切换会话或后端时取消旧请求，忽略迟到响应，禁止展示另一会话的数据。
活动日志仅在面板可见时按描述静默更新，关闭后停止。
面板生命周期不能重新挂载聊天消息或导致正文内的视频重新加载。

运行记录只载入分页元数据，用户选择后才请求生成正文及详情。正文使用安全、只读的
Markdown 展示，不启用 ESC、聊天替换协议、工具执行或任务勾选回写。
独立结果不放入消息 Store，不追加聊天气泡、正文流或后续模型上下文。

权限由后端再次核验。生成正文仅供用户查看；LLM 的默认配置工具只操作规则，
不会把运行记录正文自动送回对话。对应后台任务的状态和用量与主回复分别统计。

相关通用协议见 :doc:`dynamic_settings` 和 :doc:`workflow_tasks`。
