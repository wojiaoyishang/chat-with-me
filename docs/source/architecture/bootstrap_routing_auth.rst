启动、路由与认证
================================================================================

``main.jsx``
--------------------------------------------------------------------------------

Root 依次装配：

* ``ContextEvent``；
* Toast 与 Fatal Error Host；
* UniversalModalHost；
* ``WebSocketProvider``；
* React Router。

路由
--------------------------------------------------------------------------------

``createBrowserRouter`` 管理 Chat、Document 和 Login。``HistorySynchronizedRouter`` 监听旧代码中
仍存在的 ``history.pushState`` 路径，在 POP 时与 Router 状态校准，避免整页 reload。

认证初始化
--------------------------------------------------------------------------------

Dashboard 加载时先请求用户信息。401 由统一逻辑处理：

#. 只触发一次重定向；
#. 保存合法站内 redirect；
#. 不显示重复“加载失败”；
#. 登录后回到原路径；
#. 未认证时不加载 Notification 等受保护资源。

WebSocket 鉴权
--------------------------------------------------------------------------------

WebSocket 使用 Cookie。连接收到 4401 时停止自动重连并进入登录流程；普通网络断线才显示重试。

.. warning::

   redirect 必须限制为以 ``/`` 开头的站内路径，防止开放重定向。不要接受完整外部 URL。

StrictMode
--------------------------------------------------------------------------------

开发环境 React StrictMode 会执行 effect 挂载/清理再挂载。连接和认证代码必须幂等，不能因此创建
多个 WebSocket、重复 401 Toast 或重复事件监听器。
