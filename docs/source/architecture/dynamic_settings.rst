动态设置与后端连接边界
================================================================================

前端与后端设置
--------------------------------------------------------------------------------

设置窗口分别展示“前端设置”和“后端设置”。前端设置的目录与描述由客户端本机目录提供，
包括界面、后端连接和通知偏好；打开这些页面不要求后端提供设置目录或页面描述。
通知类型可以读取既有业务目录数据，页面本身仍由客户端定义。
目录的 ``categoryLabel`` 只作为标题，分组身份与保存键仍使用原 ``category`` 和 ``typeId``。

后端设置目录和 ``cwm.settings.v1`` 页面描述由当前后端提供，声明 ``scope=backend``。
本机页面声明 ``scope=client``。设置壳管理目录、加载、草稿、校验、保存与关闭，
不按后端页面 ID 导入 MCP、知识库、用户管理等专用组件。
``DynamicSettings`` 与 settings-runtime 共同渲染通用组件树，继续复用 shadcn/ui 和
共享 JSON 编辑器。新增普通后端设置只需后端组合已有组件，无需重新构建客户端。
本机界面能力与连接管理归客户端维护，不注册成后端设置页面。

页面包含 ``options``、``defaultOptions``、``saveMode`` 和保存操作。集合、表格、
矩阵、差异、字段组、弹窗与异步进度按通用交互分类。数据源、操作地址、条件、枚举和
字段联动均来自描述。禁止在渲染器中按业务字段名推断含义或为新功能增加专用页面映射。

页面正文从空白组件树开始渲染。页面级 ``title``、``description`` 和目录图标仅为导航
元数据，设置外壳不自动创建正文页头。标题由 ``options`` 中明确声明的 ``heading``
或资源工具栏展示；不能根据标题文字相同而自动隐藏组件。外壳仍统一处理导航、加载、
错误、草稿、滚动和保存，页面只编排内容。

视觉组件与排版
--------------------------------------------------------------------------------

前后端设置复用同一套通用视觉组件。``group`` 默认仅组织字段，``card`` 才显式添加
边框。资源集合采用紧凑工具栏和一层条目，避免集合卡片、条目卡片和属性底色面板嵌套；
明确指定 ``display=table`` 时使用表格。描述可提供纯视觉元数据，但不能借样式配置
加入领域逻辑。``profile-card`` 用有限引用组合紧凑资料与编辑字段，不单独注册账户或服务专用页面。

``group`` 可声明 ``variant=divided``：不增加卡片外框，标题下使用分隔线，组间留白
大于行间距，组内保持较浅的细线。界面偏好显式采用这一变体和单列设置行；通知仍是
紧凑列表。工具权限的矩阵分组使用独立浅边框、淡底标题和组间距，行内只保留细线，
从而区分组边界与条目分隔。展开箭头与正文共用收紧的左侧内距。

控件优先使用 shadcn/ui 原有 Button、Tabs、Separator、Accordion、RadioGroup 与 Card
的主题和布局。普通字段行保持紧凑，内容区之间才增加分组间距；不为每层添加图标底座、
阴影或大圆角。资源名称、数量和新增操作在同一个工具栏展示，说明只在必要的位置出现一次。

``profile-card`` 接收 ``id``、``title``、``subtitle``、``meta``、``actions``，以及
``options`` 或 ``children``。正文中的唯一 ``slot=avatar`` 图片上传字段放到头部，
复用该字段的上传和预览，避免重复显示头像。正文可按组件树组合字段，头部动作可容纳
退出登录；账户页面将昵称编辑与保存动作放在独立的“个人资料”分组。组件不持有账户
接口或固定业务字段，头像与昵称仍按根表单字段一起保存。

资源组件可声明 ``recordView:{type:"connection-card",state:{field,labels,tones}}``，
连接条目复用原有标题、说明、图标、属性列和动作，由同一资源组件管理请求及编辑状态。
``columnsCount=2`` 按实际内容容器宽度最多显示两列，窄容器自动回到一列；
``connection-card`` 也可作为独立的受限引用展示组件，不另建连接业务页面。
``state.busyValues`` 指定需要活动图标的状态值，仍共用受控的 ``labels/tones``；
属性列可以通过 ``when`` 条件隐藏无内容的诊断信息。
``recordView.primaryAction`` 将卡片名称呈现为可点击入口，复用同一个动作执行器及其
``when/disabledWhen`` 条件；未声明时仍显示普通文本。名称操作和页脚中的删除等动作互不触发。
``connection-card.variant=summary`` 提供无外框摘要；``readonly-text.variant=inline`` 提供
单行只读值。``text.multilineStyle=plain`` 使用简洁多行输入，保留一次标签及普通字段校验。
开关和复选设置项使用控制靠右的单行布局，复杂目录字段在完整宽度中对齐操作区。

通用设置根容器声明 ``settings-fields`` 内联尺寸容器。表单窄于 34rem 时，非紧凑字段
自动将名称和控件上下排列；开关与默认值按钮保持单行，不依据整个浏览器窗口宽度判断。
共享 JSON 编辑器的嵌套字段和新增字段区也按同一容器换行，不裁掉横向溢出以隐藏问题。
聊天侧栏的头部和正文使用一致内边距，正文独立滚动；桌面初始宽度为 360px，
仍遵守既有 256px 最小值、拖动范围和本地保存值。移动面板占可用宽度且最多 24rem，
标题允许换行，关闭按钮保持固定宽度。调整宽度不会重新挂载字段或清空草稿。

资源的 ``toolbarActions`` 在刷新和新增旁声明集合操作，条目动作仍放在 ``actions``。
二者复用同一个动作执行器、确认、禁用和吐司反馈，不按资源 ID 添加专用按钮。
本机适配器的 ``invoke(name,payload,{signal,onProgress})`` 可发布 ``message/percent``
进度；关闭所属设置界面会取消请求，迟到进度不能再更新吐司。``successText`` 支持原有
受限引用，例如 ``{response.available}``。本机集合订阅只静默重读内存快照，避免每个
进度更新又弹出“正在加载列表”。显式刷新与首次加载仍使用既有反馈。

``form-layout`` 使用 ``layout=stacked|compact``、可选 ``columns=1|2`` 和
``options`` 或 ``children`` 组合字段。它与 ``profile-card`` 都是透明表单容器，
不添加值路径，继续参与默认值、校验、保存和错误聚焦。资源编辑器与动态对话框默认
采用 stacked 排布；页面宽度自适应，具体字段可由显式布局约束，避免在宽弹窗中横跨空白。

资源的 ``editor.dialog`` 和后端返回的动态对话框根级 ``dialog`` 可指定尺寸，例如
``{"width":640,"maxHeight":800}``。二者接受像素数值；宽度限制在 320 至 1600，
最大高度限制在 240 至 1600，同时受当前视口内边距约束。非数值使用默认值，不接受
任意 CSS。高度随内容增长，超过限制时仅正文滚动。ComfyUI 工作流、服务连接、MCP
等由各自后端描述选择合适宽度，前端不按页面 ID 推断尺寸。
客户端连接资料编辑器使用 480 像素的自然宽度，同样受视口边界限制。

通知偏好采用单列紧凑列表：分组小标题、左侧名称与说明、右侧对齐开关，支持搜索，
不套卡片或使用双列。前端本机标签复用原有图标，所需静态资源随客户端发布；后端标签
使用当前目录给出的 ``preview`` 图标。

通用 ``tabs`` 组件按 ``tabs[].options`` 组织页面，标签不增加表单值路径。

服务端详情导航
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``open-settings`` 效果接收 ``{pageId,endpoint?,params?}``。纯导航动作不发送占位请求；
共享导航入口通知现有 Sidebar 设置壳打开当前后端的页面。目录页保留普通导航，编辑器在右侧
内容区提供返回与标题，不创建另一层业务弹窗。请求属于发起时的后端 ID、URL 和连接代次；
切换连接后不能请求或重放旧详情链接。关闭、切页与返回继续检查未保存草稿。

详情接口返回完整 ``cwm.settings.v1`` 描述。``layout.maxWidth`` 指定内容最大宽度（320–1800px），
``cache=false`` 阻止缓存可变编辑初值，``returnTo:{pageId,endpoint?,params?}`` 指定保存或返回时
打开的父页面或父详情，并在保存后失效相应缓存。``backLabel`` 可指定返回文案。
父详情与编辑器共用相同的后端连接代次，按声明保留设备、会话等参数，不按页面名拼接路由。
``invalidateOnSave`` 声明缓存事件标签，保存后同时失效这些标签对应的集合，避免依赖 WebSocket 才刷新新条目。
共享渲染器不依据 Workspace 等页面名选择控件；详情表单也使用当前 API 客户端、校验和操作执行器。

新增控件 ``directory-list`` 组合现有目录浏览器，接收后端提供的 roots 和 browseEndpoint；
``member-permissions`` 使用后端提供的 users、permissions 和 excludeUser，逐行选择成员与授权；
``policy-rules`` 编辑匹配器、操作范围和目录范围；``command-permissions`` 组合命令授权与既有
参数编辑器。输入错误通过通用 data-settings-invalid 通道阻止保存并定位标签页。
目录字段的 ``browseTitle/browseDescription/browseEndpoint`` 由后端描述提供，本地、远端共用
选择器。``browseDisabled`` 表示协议能力尚未开放；``aliasHistory`` 防止新增时重新分配历史
名称，``readOnlySource`` 展示工作区继承限制且不改写单目录原值。对 ``selectable=false``
的虚拟层、读取失败或未完成读取均禁用确认；失败与重试留在选择器内，加载遮罩保留布局。
客户端不按 Workspace 页面名推断远端路由或权限。

通用会话选择
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``conversation-picker`` 接收后端授权候选 ``options``，每项包含
``value/label/group/description/status/disabled``。点击完整宽度的选择行后，
使用已有 ``ConversationsList`` 的静态选择模式搜索、按组查看和确认；不发起侧栏的
发现、分页请求，也不提供删除、复制或分支管理操作。禁用候选不可选，已失效的原选择
继续显示并提示，不默认切换到首项。

自动化和机器人快捷触发描述分别提供普通会话与子智能体候选。子智能体按父会话分组，
目标选择与正文编辑在同一表单中，保存动作统一留在固定页脚。静态候选不构成权限授予，
后端仍在保存及实际投递前复核，父级权限、预算、暂停和冻结规则继续生效。

标签页与表单值
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
ComfyUI 主页面区分工作流模板与服务连接，编辑器区分基础信息与工作流参数。
切换只改变可见内容，保留各页的值和编辑草稿；隐藏页仍参加校验，失败时应显示对应页。
标签支持左右方向键、Home 与 End；只读表单仍可切换。嵌套标签和隐藏 JSON 草稿的错误
同样需要展开相关标签并聚焦，不能只检查当前可见页。

内容区域按实际容器宽度适配列数，窄屏导航保留可读标签。长参数和资源标识不得撑出窗口，
编辑对话框的正文独立滚动，操作区保持可达。明暗主题、加载、空数据、失败及只读状态
继续使用公共 UI 原语。

嵌套窗口与下拉菜单复用 WindowLayer。明确标记 ``data-window-popover`` 的自有弹层
继承窗口身份与层级；其交互不关闭父窗口，普通外部点击仍保持原行为。共享 JSON 编辑器
的纯 DOM 下拉也遵循此约定，源码在后端 packages/json-config-editor，构建后同步版本化
客户端包，不在设置页加局部超大 z-index 补丁。

共享确认框独立管理打开状态和请求文案。关闭时保留该次标题、说明、按钮及危险样式，
直到 Radix 退出动画移除弹层，避免先清空文案产生空白闪框；不通过延迟计时器补救。
每次请求具有独立身份，过期关闭回调不能取消新请求，替换请求和卸载均结束对应的等待。

资源编辑器和后端返回的详情弹窗也分别管理可见状态与本次内容。取消、关闭或保存成功
只启动退出，保留当前标题、字段、标签页与尺寸；Radix 实际卸载内容后，通过其
``onCloseAutoFocus`` 生命周期释放旧草稿。不能先置空记录，否则编辑窗口会短暂显示
“创建”标题和空正文。关闭后的草稿守卫立即注销，详情读取取消；迟到的读取、保存、
错误和退出回调用本次打开身份隔离，不能更改或关闭下一次打开的窗口。
用户、ComfyUI、MCP 和知识库连接共用该机制，不在各页面分别修补。

资源集合、编辑表单和响应详情表单分别按其实际数据与运行上下文复用渲染结果。
只改变弹窗可见状态时，不重新遍历背后的列表或仍在淡出的字段；字段值、描述、权限、
动作状态与运行上下文变化仍正常更新。每次重新打开使用新的表单身份，不跨次保留草稿。
表单构建和详情数据装载使用可中断的 React 更新，避免把大型表单的初始化全部放在
点击事件的同步路径。请求身份检查同时应用于排队中的更新，旧响应不能覆盖新窗口。
父级回传刚收到的同一个表单对象时，以引用识别，跳过重复的全量 JSON 比较；真正的
外部数据替换仍执行原有同步逻辑。隐藏标签页的挂载和校验语义保持完整。

图配置画布和离线连接管理同样由 Radix Portal/Presence 控制正文挂载，不能在内容层
再次用 ``open &&`` 提前删除子树。这样首次打开前仍按需挂载，退出期间保持完整，
动画结束后正常卸载。文本编辑和预设选择窗口保留既有的独立可见状态；本次排查未发现
相同的提前清空逻辑。窗口退出行为不使用硬编码延时，也不通过关闭动画隐藏问题。

关闭时窗口立即退出交互栈，但保持最后一次可见层级直到退出动画结束，不能在动画
开始时降到父窗口后面。Dialog 遮罩同样保留并进入 ``closed`` 淡出状态，完成后由
Portal/Presence 卸载；遮罩和正文使用相同的过渡时长。原有跨窗口激活、拖动、键盘和
自有下拉归属规则保持，正在退出的窗口不再接收指针操作。

动作与状态
--------------------------------------------------------------------------------

动作使用有限 ``$ref`` 引用 ``form``、``item``、``response`` 或 ``client``。
接口参数经过编码，只接受选定后端的 API 路径；数据转换与条件使用明确支持的操作，
不执行后端提供的代码。动作效果统一处理刷新、表单更新、弹窗、页面跳转和反馈。
后台操作继续查询既有任务或操作状态，进度查询不能重复提交业务操作。
设置目录和页面读取在右侧内容区显示活动指示，完成后自然淡入设置项；资源集合、
编辑器详情和延迟加载的图控件在自身内容区加载，不为这些读取弹出顶部吐司。
文件读取和动作请求继续使用顶部浮动吐司。按钮保留原图标、宽度和禁用状态，不再
追加行内操作进度块。动作以稳定身份更新同一条吐司，
``pendingText`` 提供初始文案，进入轮询后显示阶段、百分比及“查看详情”；读取暂停时
提供“继续读取进度”，只恢复状态查询。组件卸载时清理其提示，不取消服务端后台任务。
百分比跟随进度文案显示；服务端未提供数值时保持不确定状态。通用 ``async-operation``
在描述包含任务链接并收到任务身份时提供“查看任务”，重新打开设置后仍可进入对应任务。
成功反馈由后端的 ``effects`` 中 ``toast`` 或 ``successText`` 明确声明，前者优先，
避免同一次成功重复提示；不根据按钮名称推断含义。
吐司使用共享 ``Spinner`` 表示持续活动。其旋转不随系统“减少动画”而停止，内容淡入与
弹窗过渡仍遵循减少动画偏好；不全局恢复被关闭的装饰动画。

资源集合默认在内容卡片内加载，初次读取保留加载卡片，
刷新时覆盖原条目并保留其高度。读取失败在相同区域显示错误和重试，不另发加载吐司。
通用资源在设置壳之外仍可显式声明 ``loadingMode=toast``；设置壳和离线连接管理的
运行上下文强制采用 ``inline``，不按业务页面 ID 判断。既有 Workspace 的显式
``loadingMode=inline`` 仍是同一组件能力。
``async-operation`` 可声明稳定身份及状态恢复接口；提交结果不确定时只读取核对，
403 不触发恢复绕过。``open-dialog.value`` 可引用后端返回的完整描述，弹窗内部有独立
表单状态并使用同一动作执行器。矩阵批量联动和上传保存值／预览值分离也由描述声明。
``dialog.dismissible=false`` 禁止空白点击、Esc 和浏览器返回关闭，锁定背景交互与设置
窗口切换，但保留弹窗的明确关闭按钮；普通弹窗不受影响。``readonly-text`` 支持选择内容、
按需显示复制按钮和格式化时间，复制只在用户点击时发生。
敏感的一次性动作可声明 ``retainResponse=false``，响应仍用于该动作效果和回调，但不复制进
动作或轮询状态；弹窗退出后释放其表单数据。该机制不替代服务端授权或日志脱敏。
React StrictMode 的生命周期重放继续使用已发出的状态读取，不得留下悬空的执行提示或重复提交；
实际卸载时在下一微任务取消该组件持有的请求，不取消服务端已启动的操作。

表单草稿与服务器快照分开。保存期间的新编辑不得被较早响应覆盖，版本冲突不丢失
用户输入。资源编辑器只按描述组装可写字段；凭据不通过列表回显，也不保存到普通草稿。
未知组件显示能力错误，不把它自动当作 JSON 编辑器。

加载与窗口缓存
--------------------------------------------------------------------------------

加载完成后内容仅以透明度淡入，保留原排版；遵循系统的减少动画偏好。刷新资源时保留
已显示的条目，不插入进度行。页面失败时使用覆盖内容区的半透明背景和淡入错误面板，
保留重新加载入口；后端引导失败使用同样的全屏恢复层，允许打开本机连接管理。
吐司 Host 位于后端引导组件之外，首次连接和连接恢复阶段也可反馈进度。

前端“界面／设置窗口”提供默认开启的 ``CacheSettingsPages``。缓存是当前设置窗口的
私有内存，只保存成功加载的目录、页面描述、服务端表单初值及资源集合。切换页面可复用
这些快照，关闭窗口、切换后端或账号、关闭缓存开关都会清空；不写入 localStorage 或
IndexedDB，也不保存用户输入的未提交密码或令牌。草稿退出确认与原来的权限校验继续生效。

页面描述根级及 ``resource`` 节点可以声明 ``cache:false`` 排除对应快照。资源缓存键
包含解析后的数据源、查询参数及父记录身份，不能复用其他参数或父记录的结果。失败响应
不进入缓存。显式刷新跳过缓存，保存更新服务端快照或使页面失效；描述声明的 ``events``
同时使相关快照失效，即使页面已隐藏也不会在下次打开时恢复过期数据。缓存开关只控制
读取复用，不改变请求权限、服务端持久状态或后台操作生命周期。

目录名称与分组矩阵
--------------------------------------------------------------------------------

聊天工具菜单、会话权限和默认工具设置使用后端目录给出的友好名称，不把工具集标识或
任意目录文案当成本地翻译键。工具集与工具没有显示名称时才使用其原始名称。原始标识、
``ToolRef`` 和权限键保持稳定，显示名称及分组变化不改变工具身份或授权。
界面自身的按钮、提示和权限选项继续使用客户端本地翻译。

通用 ``matrix`` 通过 ``groups:[{id,label,description?}]`` 声明分组；扁平 ``rows``
使用 ``row.group`` 引用分组 ``id``，``row.id`` 继续作为保存键。默认展开首组，其他组
可以折叠；搜索时展示并展开命中的组，清空后恢复原折叠状态。没有分组声明时继续支持
普通矩阵并保持行顺序。

每行互斥列使用单选语义，UI 选项映射回列的原始值类型。全局批量操作处理全部可修改行，
不以当前搜索结果或折叠状态为作用范围；已有的禁用、允许值、锁定策略和危险确认继续生效。分组只影响展示，不为
默认工具增加一套权限继承，保存仍由原服务端接口处理。

``groups[].bulkActions`` 可以给分组增加“全部允许／全部询问／全部拒绝”，动作沿用
全局按钮的 ``label``、``value`` 和 ``confirm``。组内全部允许仍显示危险确认。
组操作只遍历该组全部原始行，搜索和折叠不缩小范围；锁定与允许值约束继续生效。
组操作不执行 ``set``，不改变其他组或全局 ``fallbackMode``。全局 ``bulkActions.set``
仍可执行描述中明确声明的整页字段联动。

``matrix.valueStorage`` 可声明
``{type:"entries",keyField:"pattern",valueField:"effect",unsetValue:"inherit"}``，
以键值视图编辑原有条目数组。行 ID 始终是完整字面量，不拆分含点号的标识；选择
``unsetValue`` 会移除相应显式条目，保存仍提交数组，其他条目的额外元数据保留。
``unlistedRows:{group,description}`` 将已有但不在当前目录中的条目显示到声明分组，
允许检查与移除，避免因目录变化静默丢失原有规则。未知存储格式明确报错。

用户编辑器由后端声明“账户信息／工具分配”标签页，工具分配复用相同分组矩阵及搜索、
单项和整组操作。全局 ``*``、工具集 ``toolset.*`` 和精确工具路径分别保留原有优先级，
继承表示删除该层显式规则。分配仅决定是否可用工具，不增加“询问”分配值，也不替代
调用审批；管理员仍使用服务端的全部已启用工具规则。全局及组内“全部分配”保留危险确认，
组内操作不改其他组；工具集默认规则仍适用于以后新增工具。后端继续验证操作者权限。

全局和组内批量按钮的图标、颜色由动作的 ``icon``、``tone`` 声明；默认工具使用
``shield-check/success``、``circle-help/warning``、``shield-x/danger`` 区分允许、
询问与拒绝。渲染器只接受受控的图标与主题色，不按标签文字推断含义。展示元数据不改变
权限，危险确认仍由原 ``confirm.danger`` 控制。
批量按钮采用 ``variant=ghost``，保留图标和完整文字。受控 tone 为 success、warning、
danger、info，显式 tone 优先于危险确认的默认颜色，允许按钮可显示绿色并继续要求确认。
未知图标不显示，未知 tone 使用受控默认策略，不接受任意 CSS。网络动作忙碌时禁用按钮，
加载进度由浮动吐司展示。

扩展组件
--------------------------------------------------------------------------------

``registerSettingsComponent`` 注册的是可复用控件类型。``node-graph`` 接收已解析的
图值，支持节点搜索、拖动缩放、子图导航、参数绑定和产物选择。字段的目标、类型和默认
策略由后端提供；参数面板仍调用通用字段渲染器，不引用第三方业务专用设置页面。
图布局算法在通用模型中共享，避免旧页面与新组件出现两份布局逻辑。

运行观测渲染器以带摘要的版本化产物随客户端发布。普通 ``--check`` 校验本仓库产物，
无需邻接的后端源码目录；维护者更新时通过 ``--source`` 明确提供唯一源码位置。
通用组件的构建依赖与运行时选定的后端地址互相独立。

后端选择与隔离
--------------------------------------------------------------------------------

客户端将后端配置和当前选择保存在 localStorage，直到用户在客户端明确切换。刷新继续
使用同一选择，断线或登录失效不能自动切换。初始同源部署仍可使用 ``/api`` 入口。
登录凭证按后端隔离在 sessionStorage，密码不进入连接配置。

连接失败时，恢复界面淡入显示 ``Oops!`` 和连接说明，左侧为断开的客户端／服务器
图形，右侧集中显示原始错误、当前后端名称与地址，以及重试／管理连接按钮。
窄屏自动改为上下排列。装饰运动遵循减少动画偏好；小状态灯保留轻微透明度变化，
不表示正在自动重连。失败页不更换当前选择，也不替代登录或会话校验。

“前端设置／后端连接”和离线连接管理共用本机描述，提供“全部测速”和单项“测速”。
测速为浏览器访问公开 ``GET /client/bootstrap`` 并读取响应体的往返延迟，单位为毫秒，
不测下载带宽或 Worker 排队时间。每次点击快照已配置地址，最多并发三个请求，单项
八秒超时；逐项发布等待／检测中／可连接／超时／协议不匹配／失败，并最终汇总数量。
只有成功响应符合 ``cwm.client.v1`` 才显示可连接；HTTP 错误和浏览器网络／跨域失败
分别提供说明。测试结果只存于当前标签页内存，按配置身份与地址绑定，不写连接配置，
不因排序或重命名错配。关闭所属界面取消未完成检测；重开可以查看已完成结果并重新测速。

公开入口测速有意使用不携带凭证、不走 HTTP 缓存、不跟随重定向的独立读取，避免经过
当前 API 客户端的登录／凭证拦截器。它不是另一套业务 API 客户端，不初始化会话、不
更新 manifest、不自动切换后端，也不向其他地址发送当前登录令牌。实际业务请求继续
使用下述统一连接上下文。

HTTP、控制 WebSocket、实时语音、资源 URL 和页面消息使用同一个连接上下文。
请求带有连接代次，旧连接的响应和事件不能更新新后端。离线待发队列属于原连接，禁止
随新连接重新发送。手动切换检查未同步文档并保留草稿，再重新加载客户端以清理旧单例；
切换本身不取消后端已经接受的任务。

业务状态按后端与用户隔离，包括任务、执行模式、通知、消息配置目录、文档卡片定义、
聊天草稿和文档离线数据；设备外观偏好仍共用。``cwm://`` 引用由所属连接解析。
后端托管页面通过明确来源与 frame 身份校验通信，跨源读取使用受限凭证。
管理页的业务请求由宿主桥代理；长期登录令牌不进入 frame，凭据接口及其编码变体均禁止
从桥访问。设备偏好读写拒绝连接配置及后端数据保留命名空间，未知存储作用域明确报错。

技能设置
--------------------------------------------------------------------------------

后端通过通用 Resource、Tabs、文件输入、矩阵和表格提供“技能”标签页；前端无 Skills 业务页面分支。
清单、详情、完整包版本、资源预览、授权、导入更新、设备部署和激活取消均来自描述和动作接口。
预览不会激活技能。目录预览和版本元数据有显示界限，完整资源由工具分页读取。
手动同步提交普通后台工作流，通过既有 watch/任务详情查看进度，不改变卡片布局。

执行字段与 allowed-tools 的解释由后端说明提供：声明只收紧工具范围，不扩大权限或跳过审批。
未知执行字段、缺少目标或旧 Agent 通过正常错误反馈显示，不在前端猜测或启动降级路径。

只读图像
--------------------------------------------------------------------------------

``readonly-image`` 是通用展示原语，不包含微信或其他业务页面逻辑。后端通过字段值提供
嵌入式 PNG/JPEG/GIF/WebP 像素或项目内资源引用，并指定 ``alt``、``width``、``height``；
组件不提供上传、删除或编辑入口。尺寸限制为 32–640 像素，并受父容器宽度约束。
来源拒绝第三方绝对 URL、协议相对 URL、反斜线、换行、活动 SVG 数据和超长内容；
项目引用仍交由当前连接的资源解析器处理。登录二维码由后端本地编码生成，不交给外部
二维码服务，不把 Bot 凭据或回复上下文放进描述。扫码状态、验证码及完成动作继续使用
普通字段、动作和对话框协议；资源刷新与退出动画沿用公共实现。

描述弹窗页脚与状态观察
--------------------------------------------------------------------------------

后端可在描述根级指定 ``footerActions`` ，客户端将这些动作放在固定页脚右侧，
与关闭按钮同排。动作读取当前主体表单值，提交前校验必填字段、选项有效性和
JSON 编辑器状态；请求及确认仍复用公共执行器。关闭回调固定到发起动作的弹窗
实例，不允许旧请求结束时关闭后来打开的新弹窗。

选择字段只有值与选项明确匹配时才显示选项名。空值显示后端指定的 ``placeholder``
或“请选择”，不再以第一项冒充已选择。已失效的旧值显示重新选择提示并阻止提交，
后台仍独立核验实际身份，空目标与真实无权访问分别作为表单错误和权限错误处理。

描述弹窗可提供 ``poll.action`` 和 ``poll.intervalMs`` ，用于自动读取下一份描述。
请求顺序执行且不叠加，不经过动作吐司或执行副作用；响应更新同一个弹窗。
``preserveFields`` 指定需要保留的未提交字段，``refreshTargets`` 在终止轮询时
刷新所属集合。返回描述不再含 ``poll`` 时停止，关闭或替换弹窗会取消在途请求并
忽略迟到响应；页面不可见时暂停。验证码输入状态由后端移除轮询配置，等待手动提交。

资源可指定 ``refreshIntervalMs`` 进行有界的静默刷新。保留已显示的卡片，不重新
显示加载占位；隐藏标签页、页面不可见或组件卸载后不继续发起请求。发送记录只
反映接口处理状态，“已提交”不能被解释为微信用户已读。

提示与连接图标
--------------------------------------------------------------------------------

通用提示浮层和设置 ``tips`` 同时限制到可用视口宽度，并允许在长 JSON、URL 或连续
标识符中换行。文本保留完整且可选择复制，不以截断或禁止选择来掩盖溢出。
``recordIcon`` 接收通用图标词汇（包括 ``message-circle``）或资源引用；符号图标
直接渲染单色 SVG，不将图标名作为图片 URL 请求。后端资源图标应使用
``cwm://public/...``，避免相对前端源地址；侧栏 SVG 使用无底板的 24 像素线稿。

编辑器预览复用通用 ``patch`` 效果，只合并响应中的预览字段到当前表单，保留尚未保存
的源码与示例输入。预览不能重新打开弹窗或暗中保存，保存仍使用根级 ``footerActions``。

代码字段与资源动作菜单
--------------------------------------------------------------------------------

``code-editor`` 是通用代码文本字段。后端指定 ``name``、``text``、``language``
（``jinja2`` 或 ``text``）、``editorHeight``（默认 260，限制为 160–640 像素），
以及可选 ``placeholder``、``readOnly``、``maxLength``、``tips`` 和 ``description``。
未知语言使用纯文本显示，所有内容只编辑不执行；语法高亮不替代后端模板安全校验。

编辑器使用按需加载的 CodeMirror，提供行号、Jinja 插值/条件/注释着色、两空格
Tab 缩进、Shift+Tab 反缩进、撤销/重做按钮及系统快捷键、全选。底部显示快捷键提示，
Esc 后按 Tab 可移出编辑器。保存仍由所在表单的固定页脚操作负责，编辑器不吞掉
Ctrl/⌘+S 后无声地假装保存。外部表单补丁只替换改变的文字范围，不重建视图或撤销栈；
输入法组合期间延后替换，只读配置通过重配置生效，卸载销毁编辑器及计时器。

资源可指定 ``recordView.actionLayout="split-menu"``，将主要动作保留为按钮，
其余动作收进更多菜单；``recordView.moreLabel`` 指定菜单名称，动作上的
``placement="menu"`` 可显式放入菜单。客户端按后端声明组织动作，仍复用原有
权限、禁用条件、确认、请求和刷新协议，不按资源或页面名称分支。

同一数据字段可按格式选择使用互斥的 ``when`` 呈现：例如纯文本使用多行 ``text``，
Jinja 源码使用 ``code-editor``，两者都指向同一个 ``content``。描述不得分别指定
竞争的默认值，保存只读取唯一数据路径，格式切换与重新打开保留草稿。相关格式与固定
角色选择可使用通用 ``form-layout`` 双列布局，窄屏折为一列；角色仍是普通静态枚举，
不执行模板或依据事件内容推断身份。

草稿配置弹窗
--------------------------------------------------------------------------------

``open-dialog`` 效果可显式给出 ``target="form"`` 或合法 ``form.<path>``，绑定
打开动作所属的草稿表单。路径拒绝原型链片段，不能访问客户端存储或其他作用域。
内部弹窗的 ``apply-dialog`` 将解析后的纯数据写回该绑定目标并关闭，取消则不改父稿。
支持可选 ``guardFields``（如 ``["conversationId"]``），在请求开始时捕获这些字段，
打开和应用时均核对；其他正文编辑不会因此丢失。源表单关闭、卸载、替换或重新打开后，
迟到结果不能写入新的表单。

同一配置窗需要按新模型重新载入描述时，可使用 ``open-dialog`` 的 ``replace=true``，
保留原结果绑定并替换当前层，不增加第三层窗口。它不能同时声明新的 ``target``。
需要后端校验时，应用动作可以先调用不持久化的校验接口，再把返回值交给
``apply-dialog``；正式保存仍由外层表单负责。页面不通过响应传递回调函数。

自动化的“对话发送设置”使用这些通用协议，由后端提供发送、工具权限、高级选项
三个标签页。继承开关属于弹窗草稿，提交时由后端适配成只含明确覆盖值的
``sendSettings``。工具矩阵复用规范权限键、分组与批量允许警告，不添加业务专用 React 页面。

相同数据路径也可按格式互斥显示不同的说明与标签。例如 ``includeEvent`` 在纯文本
显示“包含触发事件内容”，在完整正文模板下显示“携带事件附件”；两种呈现共享开关值，
不额外创建默认值或由客户端推断业务语义。标签和帮助文字均来自后端描述。

测试要求
--------------------------------------------------------------------------------

自动化设置由后端的资源集合、标签页、字段和动作组成，客户端不注册自动化专用页面。
任务管理中的“计划任务”是后端托管页面的独立视图，任务面板可直接跳转到
``/tasks?view=schedules``。宿主只透传管理视图与身份隔离的请求桥；计划表单、模板输入、
启停、触发历史及 Worker 任务链接全部由后端提供，不在前端持有另一份计划规则。
计划编辑采用“运行安排 / 工作流与输入”标签页。Cron 使用后端共享解析器校验并预览五次
执行时间；空模板禁用载入和保存，并提供创建模板入口，不发送缺失模板 ID 的请求。
时间预览防抖并取消过时请求；不把预览注册为真实计划或后台任务。
