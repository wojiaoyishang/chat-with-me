新增页面或路由
================================================================================

设置页面
--------------------------------------------------------------------------------

普通后端设置无需创建 React 页面或新路由。请在后端所属领域注册设置描述，组合通用字段、
资源和动作。界面、连接与通知偏好则在客户端本机目录中组合相同组件，不依赖后端设置目录；
协议及扩展边界见 :doc:`/architecture/dynamic_settings`。
只有缺少可复用的交互原语时才扩展组件注册表，不以业务名称注册整页。
页面正文完全由 ``options`` 编排，``title`` 与 ``description`` 只作为目录元数据。
需要可见标题时显式放置 ``heading`` 或资源工具栏；字段组织使用无边框的 ``group``，
需要一层边框时再使用 ``card``，不依赖设置外壳生成装饰或重复标题。

步骤
--------------------------------------------------------------------------------

#. 在 ``src/pages`` 创建页面装配组件。
#. 在 ``main.jsx`` Router 增加路径和 ``errorElement``。
#. 明确 URL 中使用的公共 ID。
#. 认证页面等待用户初始化，不提前请求受保护资源。
#. 复杂业务下沉 ``features/<domain>``，页面只组合。
#. 更新浏览器历史同步规则和文档。

示例
--------------------------------------------------------------------------------

.. code-block:: jsx

   {
       path: '/reminders',
       element: <ReminderPage/>,
       errorElement: <RouteErrorPage/>,
   }

路由状态
--------------------------------------------------------------------------------

优先使用 Router navigate，不新增直接 ``history.pushState``。必须兼容旧路径时，通过
``browserHistoryLayers`` 统一订阅和清理。

.. important::

   Conversation 和 Document ID 要分别放在参数名中，不能重新使用 ``markId`` 或通用 ``id``。
