用户管理界面
================================================================================

“用户管理”动态设置页提供账户资料、启用状态、管理员状态和工具分配。当前登录管理员的
“启用账户”和“管理员”开关必须锁定，删除按钮也必须禁用；后端会再次执行相同约束，
前端锁定仅用于避免误操作。

工具分配区使用三层规则：总体默认（``*``）、工具集（``toolset.*``）和单工具。
总体默认只有“允许/拒绝”；工具集和单工具支持“继承/允许/拒绝”。工具集默认折叠，
用户可以搜索工具集名称、工具名称或路径，搜索命中时相关分组自动展开。

设置主窗口只允许改变大小而不改变屏幕中心位置。尺寸通过 ``src/lib/tools.jsx`` 中的
``getLocalSetting`` / ``setLocalSetting`` 保存。动态设置内容区不得使用固定的 ``max-w``，
应随设置窗口可用宽度增长。
