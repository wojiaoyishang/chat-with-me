用户管理界面
================================================================================

“用户管理”动态设置页提供账户资料、启用状态、管理员状态和工具分配。当前登录管理员的
“启用账户”和“管理员”开关必须锁定，删除按钮也必须禁用；后端会再次执行相同约束，
前端锁定仅用于避免误操作。

工具分配区由后端组合通用规则列表与选择控件，使用总体默认（``*``）、工具集
（``toolset.*``）和单工具路径。规则值为分配或拒绝，删除显式规则恢复继承。
后端工具目录提供可选路径与名称，客户端不持有业务授权树或 MCP 工具名称映射。

设置主窗口只允许改变大小而不改变屏幕中心位置。尺寸通过 ``src/lib/tools.jsx`` 中的
``getLocalSetting`` / ``setLocalSetting`` 保存。动态设置内容区不得使用固定的 ``max-w``，
应随设置窗口可用宽度增长。表单字段可通过显式 ``form-layout`` 选择 stacked 或 compact
排布及一／两列，在宽窗口中保持合理阅读宽度；页面容器自适应不要求每个输入控件撑满整行。
