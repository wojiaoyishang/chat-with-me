## 项目定位与技术栈

面向 AI Agent 的实时交互前端，支持文本、语音、工具审批、Widget、Story、Workspace、在线文档、多分支 Conversation 和 Message History Map。

配套后端：`E:\Programming\Python\Chat-With-Me-Backend`，维护入口为其 `docs/交接文档.md`。HTTP 用于资源快照与管理，WebSocket 用于语义事件和流式状态；前端展示后端状态，不自行建立第二套执行或审批权威。

已从 package/config 确认：React 19、Vite 7、React Router 7、Zustand 5、Axios、Tailwind CSS 4、Radix/Headless UI、i18next、Markdown/KaTeX/代码高亮。主要业务为 JS/JSX，部分公共 UI 为 TS/TSX；使用 ESM，`@` 映射 `src/`。依赖精确安装由 `package-lock.json` 管理。

## 已确认的维护规范

1. **Protocol v1**：只发送/接收二进制 Frame，MessagePack 控制元数据和 raw media body。小写点分事件名；请求/回复依靠 `event_id/reply_to`。不恢复旧 JSON `target/command/markId` 协议。
2. **传输边界**：页面通过 `emitEvent/onEvent` 使用语义事件，不接管 WebSocket 协议；新增事件联动后端 catalog/envelope、前端 EventName、订阅和文档。
3. **事件作用域**：区分 Conversation/Document/Turn/Run/Stream。需要消费用户全局事件时显式 `includeGlobal: true`；Hook 订阅返回清理函数，防止多页面/StrictMode 重复监听。
4. **流式调度**：模型 delta 保持 FIFO，审批/回复等交互可穿插；不得为交互丢弃模型 delta。媒体保持 incoming 身份，不以 localOnly 重发代替入站分发。
   监听器在事件实际交付时匹配，不能在到达时绑定一个即将被 React 清理的 registration；`conversation.messages.*` 与 `message.*` 使用同一 stream FIFO。
5. **状态划分**：URL 管选择和页面模式；HTTP 管持久资源快照；实时状态管运行增量；组件/Hook 管局部交互。跨组件稳定状态用 Store，大对象使用 selector，高频 delta 合并，避免全树重渲染。
6. **Event Store 边界**：事件记录/监听器/Reply Waiter/去重/调试不是业务数据库，不能无界积累 envelope；终态后从 HTTP/服务端快照校准业务历史。消息摘要重读尾部并按 `orderIndex` 替换，不能只追加新 messageId。
7. **Execution 投影**：后端 Execution 是权威，Task Window 归属创建它的 Assistant 消息；切换分支/对话、删除/重生成时清理孤立窗口。cancel 显示 cancelling，终态等待 Worker；resume 是新 Run。
8. **状态卡片**：空 `executionStatus` 是删除瞬态行信号，不补成成功状态。工具卡按具体 toolCallId 隔离，显示名称和 guidance 等阶段语义优先采用后端元数据。
9. **Workspace 传输**：transferId 是传输身份，toolCallId/executionId 是归属索引。聊天和 Task Window 复用 WorkspaceTransferCard 与同一 Store；AttachmentShowcase 展示文件实体，不持有第二套传输生命周期。
10. **资源路径**：`cwm://workspace/@<workspaceId>/<path>` 是不透明资源标识，不转换成宿主/相对路径或浏览器 URL。
11. **HTTP/权限/UI**：优先使用统一 apiClient 的认证与错误语义；审批/权限控件只是后端策略投影。新 UI 遵循既有 Feature、公用组件、样式和国际化组织，不让实现细节泄露进产品流程。

约束依据：根 README、`docs/source/architecture/state_management.rst`、`event_flow.rst`、`src/features/execution/README.md`、`src/features/workspace/README.md` 与实际入口/Transport 集成代码。
